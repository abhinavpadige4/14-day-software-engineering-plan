# 14-Day Software Engineering End-to-End Study Plan

This repository contains a comprehensive 14-day study plan designed to cover essential software engineering topics for interview preparation and practical skills development.

## Plan Overview

- **Duration**: 14 days
- **Focus Areas**: 
  - Data Structures & Algorithms (Arrays, Strings, Linked Lists, Trees, Graphs, Dynamic Programming)
  - System Design
  - Backend Development (Python FastAPI + SQL)
  - Frontend Development (React + TypeScript)
  - DevOps (Docker, CI/CD with GitHub Actions)
  - AI/ML (RAG, LLMs)
  - Integrated Project & Mock Interviews

Each day includes theory, coding problems, MCQs, and mock interview practice with specific time allocations.

## Files

- `plan.md` - Detailed day-by-day breakdown with hours, resources, coding problems, MCQs, and mock interviews
- `resources.md` - Curated list of all referenced resources with direct links

## How to Use

Follow the daily schedule in `plan.md`, complete the coding problems, review the resources, and practice mock interviews as outlined.
