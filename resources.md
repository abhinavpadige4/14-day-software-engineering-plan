## How to Use These Resources
1. Follow the day-by-day plan in `plan.md`
2. For each topic, start with the theory resources
3. Solve the coding problems listed (LeetCode links can be constructed from problem numbers)
4. Practice MCQs from the suggested sections or create your own
5. Participate in mock interviews using the suggested platforms
6. Build the integrated project as outlined in Days 12-13
7. Review and practice on Day 14

## Notes
- All resources are free to access.
- LeetCode problems can be accessed directly by searching the problem number and title on LeetCode.com.
- For MCQs, look for quiz sections in the Tech Interview Handbook or create flashcards.
- Adjust the pace based on your background and available time.
